# Programação Web 2

##  Sobre a disciplina

A disciplina de **Programação Web 2** tem como foco o desenvolvimento de aplicações web, com ênfase na construção da **interface e do Front-end** das aplicações.

Durante a disciplina, são estudados conceitos e tecnologias utilizados no desenvolvimento de aplicações modernas, buscando compreender desde os fundamentos do desenvolvimento para a web até a criação de interfaces interativas e componentes reutilizáveis.

##  Objetivo

O objetivo deste repositório é **organizar e armazenar as atividades, exercícios, projetos e estudos desenvolvidos ao longo da disciplina de Programação Web 2**.

Através das atividades, busca-se desenvolver conhecimentos práticos sobre o desenvolvimento Front-end e compreender como as diferentes tecnologias utilizadas no ecossistema web podem ser aplicadas na construção de aplicações.

## 🛠️ Tecnologias

As principais tecnologias e ferramentas utilizadas ao longo da disciplina incluem:

* **HTML5** — estrutura das páginas
* **CSS3** — estilização e layout
* **JavaScript** — lógica e interatividade
* **React** — desenvolvimento de interfaces utilizando componentes
* **Git** — controle de versão
* **GitHub** — armazenamento e organização do código

##  Propósito do repositório

Além de servir como espaço para entrega e organização das atividades acadêmicas, este repositório também funciona como um **registro da evolução dos conhecimentos em desenvolvimento web**, permitindo acompanhar a aplicação prática dos conceitos estudados durante a disciplina.
